# Overview

This repo is for players of the popular game Last Letter! 

Some features include:
+ Accessible UI for fast control.
+ Quickfire mode to instantly find next possible combinations.
+ Decently optimized search tool for less browser lag.
+ Ability to search words beginning or ending with _____.
+ Ability to filter out words by length.
+ Shortcuts such as tab to auto-reset into the next word.
+ More features I'm forgetting...
