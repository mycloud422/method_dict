# Overview

This repository is for players of the popular game Last Letter!

Some features include:
- Accessible UI for fast, effortless control.
- Quickfire mode to instantly find valid word combinations.
- Optimized search tool to minimize browser lag.
- Ability to search for words starting or ending with specific letters.
- Ability to filter words by length.
- Shortcuts such as Tab to auto-reset for the next word.
- And more quality-of-life features...
